## Funcionalidades

- Listagem de lojas na tela inicial.
- Navegação para detalhes de cada loja.
- Cadastro de novos locais com validação básica de campos.
- Interface adaptada para uso com stack navigation.
- Estrutura preparada para evoluir para uma API real no futuro.

## Tecnologias

- Expo
- React Native
- TypeScript
- React Navigation

## Como executar

1. Instale as dependências:

```bash
npm install
```

2. Inicie o projeto:

```bash
npm start
```

3. Se preferir, você pode abrir diretamente em uma plataforma específica:

```bash
npm run android
npm run ios
npm run web
```
